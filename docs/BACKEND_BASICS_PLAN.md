# 백엔드 기본기 학습 플랜 (하루 30분)

[PROJECT.md](./PROJECT.md)의 "4주 로드맵(기초 개념 트랙)"을 하루 30분씩 소화할 수 있게 8주(주 5일, 총 40일)로 다시 나눈 버전이다. 다루는 주제와 최종 목표(영화 예매 앱 백엔드)는 동일하고, 하루 분량만 잘게 쪼갰다.

- **하루 30분, 주 5일(평일) 기준** — 주말은 예비일로 비워둠(밀린 날 따라잡기용)
- 기술 스택: Java, Spring Boot, Spring Data JPA, PostgreSQL, Spring Security, JUnit5 + Mockito (PROJECT.md 4절과 동일, Redis/Batch/분산세션은 범위 밖)
- 도메인은 실제 만들고 있는 영화 예매 앱(Movie/Showtime/Booking/Payment)을 그대로 사용 — 개념만 배우고 끝나지 않고 바로 내 프로젝트에 적용

## 1주차 · 스프링 부트 구조 이해 + 환경 세팅

| 일차 | 30분 학습 내용 |
|---|---|
| 1일차 | 계층형 아키텍처(Controller–Service–Repository) 개념 정리 — 왜 계층을 나누는지, 각 계층의 책임 |
| 2일차 | Spring Initializr로 프로젝트 생성, 폴더 구조 살펴보기, `application.yml` 기본 설정 |
| 3일차 | Movie 엔티티 클래스 작성 (`@Entity`, `@Id`, 필드 설계) |
| 4일차 | `MovieRepository`(JPA Repository) 작성, H2 콘솔 연결해서 테이블 확인 |
| 5일차 | `CommandLineRunner`로 Movie 저장/조회 테스트 — 실제 DB에 데이터 들어가는 것 눈으로 확인 |
